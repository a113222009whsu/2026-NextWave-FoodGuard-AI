# 證據保全引導與後續影像擴充規劃

> **現況說明**：初賽原型不進行影像辨識模型訓練，重點在於建立「可留存證據」的保全流程、困難測試情境清單與風險防線；影像物件偵測模型訓練列為後續擴充規劃。

## 1. 證據保全引導流程（核心重點）
1. **拍攝餐點與異常狀況**：記錄餐點全貌與疑似異物（如頭髮、蟲、塑膠片）或變質（如發霉、酸敗）之畫面。
2. **拍攝包裝與有效日期**：留存外包裝、標示或有效日期等資訊。
3. **截圖訂單與客服對話**：保存訂單明細、時間與平台／店家互動紀錄。
4. **存證與保留實物**：加上時間戳記與雜湊值（Hash）輔助完整性，並提醒保留實物（視情況冷藏），必要時可依規定送驗。
5. **身體不適提醒**：若出現身體不適，提示先就醫並保留就診證明，系統不提供醫療診斷。

## 2. 測試情境與干擾因素清單
- **環境與畫面干擾**：外送餐盒蓋反光、昏暗燈光、強光過曝、醬汁或湯水遮蔽、背景複雜與細小異物等。
- **測試與迭代方式**：由團隊整理測試案例回饋給技術端進行提示詞與檢索結果測試，並將檢索錯誤、拒答邊界與草稿缺漏逐筆記錄、分類與修正。

## 3. 後續影像擴充與隱私防線
- **後續擴充評估**：公開食物影像資料集多為蔬果或特定食材，與外送餐盒及異物情境存在落差，未來若導入自動偵測模型，需審慎評估資料來源、授權條款與標註成本。
- **個資去識別化**：處理訂單截圖或照片時，引導或自動模糊人臉、姓名、電話與地址等個資。
- **定位邊界**：照片與輔助資訊僅供舉證參考，無法單憑畫面證明異物來源、因果關係或認定店家違法。
