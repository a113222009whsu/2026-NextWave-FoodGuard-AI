# RAG 檢索、防幻覺與文書草稿生成設計

## 1. 知識庫來源與版本管理
- **法規資料**：以全國法規資料庫之《食品安全衛生管理法》、《消費者保護法》、《民法》等條文為主，記錄**法規名稱、條號、修正日期與施行狀態**。
- **平台條款與實務參考**：納入 foodpanda、Uber Eats 等外送平台公開條款／退款規範摘要，以及司法院公開裁判書案例參考（標註資料來源與擷取／檢視日期）。

## 2. 檢索與生成流程
1. **情境與問題解析**：結合使用者輸入的事件情境（外送餐點／校園餐廳、異物／變質、是否身體不適）與查詢問題。
2. **法規與條款檢索**：透過向量／樹狀索引檢索相關條文與條款片段。
3. **引用檢核（Citation Check）**：檢核輸出提及的條號是否確實出現在檢索到的參考片段中；若缺乏足夠依據，不進行臆測。
4. **白話說明與草稿產出**：以白話說明可能涉及的規範與救濟途徑（平台／店家反映、地方衛生局或 1919 食安專線），並產出客訴信或檢舉函草稿，由使用者確認事實欄位後自行送出。

## 3. 安全拒答與免責機制
- **查無依據即拒答**：當知識庫未涵蓋相關條文或資訊不足時，明確拒答並引導至 1919 食安專線、地方衛生局或消保／法律諮詢管道。
- **固定免責聲明**：所有輸出均附帶聲明，說明本系統為法律資訊輔助工具，不構成正式法律意見，亦不判定店家是否違法；若出現身體不適，提示先就醫並保留就診證明。
