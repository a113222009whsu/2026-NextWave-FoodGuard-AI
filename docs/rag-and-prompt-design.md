# RAG 檢索、引用檢核與文書草稿生成設計

## 1. 知識庫來源與版本管理
- **法規資料**：以全國法規資料庫之《食品安全衛生管理法》、《消費者保護法》、《民法》等條文為主，記錄**法規名稱、條號、修正日期與施行狀態**。
- **平台條款與案例參考**：納入 foodpanda、Uber Eats 等外送平台公開之使用條款與退款／客服規範，以及司法院公開裁判書作案例參考（註明來源與檢視日期）。

## 2. 檢索、檢核與草稿產出流程
1. **情境與事實確認**：依使用者輸入或確認之事件事實（外送平台或校園餐廳、異物或變質、時間與留存證據狀況）整理查詢重點。
2. **法規與條款檢索**：檢索相關法條與平台條款片段。
3. **引用檢核**：確認輸出提及的條號確實出現在檢索到的參考資料中；若缺乏明確依據，不進行臆測。
4. **白話說明與信函草稿**：以白話說明可能涉及的規範與可行救濟途徑，並產出客訴信或衛生局檢舉函草稿，由使用者確認事實欄位後自行送出。

## 3. 安全拒答與免責機制
- **查無依據即拒答**：當知識庫未涵蓋相關條文或依據不足時，啟動安全拒答並轉介地方衛生局、1919 食安專線或消保／法律諮詢管道。
- **固定免責聲明**：所有輸出均附帶聲明，說明本系統為法律資訊輔助工具，不構成正式法律意見，亦不判定店家是否違法，且不保證求償或檢舉結果。
