# 食安糾察隊 FoodGuard AI — 外送與校園餐廳食安糾紛舉證與檢舉求償助手

> **重要定位與免責聲明**：本專案為「法律資訊輔助與舉證引導工具」（Proof of Concept / 初賽雛形階段），**不構成正式法律意見、不提供醫療診斷、不判定店家是否違法，亦不取代律師或主管機關（如地方衛生局、1919 食安專線）之認定**。所有法條與救濟資訊僅供使用者參考，實際權益與行政／民事處理仍以現行法規、主管機關及司法認定為準。

## 專案簡介
大學生日常高度依賴外送平台與校園餐廳，遇到餐點異物（如頭髮、蟲、塑膠片）或食物變質（如發霉、酸敗）時，常面臨「當下沒留證據、看不懂法條與平台退款規則、寫客訴信或檢舉函太花時間」的問題。

**FoodGuard AI** 初賽原型聚焦於：
1. **證據保全引導**：引導依序拍攝餐點、包裝、截圖訂單與客服對話，加上時間戳記與雜湊值（Hash）存證、提醒保留實物與落實個資去識別化（模糊化人臉、姓名、電話與地址）。
2. **法規與條款 RAG 檢索**：檢索《食品安全衛生管理法》、《消費者保護法》、《民法》與外送平台公開條款，附上條文出處、修正日期與施行狀態；若檢索不到明確依據，啟動「安全拒答」並轉介官方管道。
3. **文書草稿生成**：協助整理經使用者確認的事實欄位，一鍵生成給外送平台／店家的客訴信與給衛生局的檢舉函草稿。

> 影像物件偵測模型訓練暫不列入初賽實作，規劃於後續階段視資料與需求逐步擴充。

## 系統架構與原型規劃
- **介面與流程原型**：規劃「拍照存證」與「生成信函」兩大入口，涵蓋外送餐點與校園餐廳情境（以 Figma／Notion 與輕量化框架呈現概念與流程）。
- **證據與情境整理模組**：引導留存餐點、包裝與訂單證據，並可結合多模態理解或使用者輸入擷取店家、平台與用餐時間等事實欄位。
- **法規檢索與生成模組（雛形開發中）**：基於 LlamaIndex + LLM 建構法規與條款檢索原型，搭配引用檢核與安全拒答機制，並產出客訴信與檢舉函草稿。

## 如何執行（目前為本地／測試雛形）
1. 安裝相依套件（如 `llama-index`、`requests` 等）。
2. 若要測試 RAG 檢索原型，請先啟動本地 LLM／Embedding 服務（如 Ollama）並備妥法規純文字／Markdown 測試資料，再執行 `prototypes/rag_law_prototype.py`。
3. 若只想測試信函草稿產生器，可直接執行 `prototypes/letter_draft_generator.py`。
